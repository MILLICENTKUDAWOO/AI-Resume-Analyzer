# 🚀 AI Career Coach Pro

An AI-powered Resume Intelligence Platform built with Flask and Python.

AI Career Coach Pro analyzes resumes, extracts skills, evaluates ATS compatibility, recommends career paths, and provides personalized improvement suggestions to help job seekers improve their career profiles.


## ✨ Features

### 📄 Resume Analysis

- Upload PDF resumes
- Extract resume text automatically
- Analyze resume structure and quality


### 🧠 AI Resume Intelligence

- Resume health scoring
- ATS compatibility scoring
- AI-generated resume summary
- Skill detection


### 🎯 Career Recommendations

- Recommended career paths
- Skill gap analysis
- Job compatibility scoring


### 🎤 Interview Preparation

Generates interview questions based on detected resume skills.


### 📊 Career Roadmap

Provides suggestions on:

- Technical skills to learn
- Portfolio improvement
- Career development steps


### 📄 PDF Report Generation

Download a professional AI-generated resume analysis report.


## 🛠 Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Natural Language Processing
- PDF Processing
- ReportLab
